CSV format and limits

Use this exact header. Quote fields containing commas or quotes.

instance,name,object_type,function,address,data_type,byte_order,scale,offset,units,bit,states,length,poll_ms,description
object_typeAI, BI, MSI, or CSV
function1: coils · 2: discrete inputs · 3: holding registers · 4: input registers. All reads.
addressZero-based Modbus wire address. Do not add a 3xxxx or 4xxxx prefix.
data_typeu16, s16, u32, s32, f32, bit, ascii, or bool
byte_orderAB or BA for 16-bit values and ASCII; ABCD, BADC, CDAB, or DCBA for 32-bit values. Leave blank for bool.
scale / offsetNumeric conversion after decoding. Use the source device’s documented units.
statesMSI labels separated by |, up to 16 states. Each label: 63 characters maximum; combined field: 512. BACnet states start at 1.
lengthASCII length, up to 20 characters.
poll_msRequested polling interval: 1000–3600000 milliseconds.
name / descriptionPoint name: 63 characters maximum. Description: 127. All CSV fields: 512 characters maximum.

The gateway checks types, ranges, duplicate objects, and compatible field combinations. Review any validation error before saving.

Configuration loaded

Saving restarts the gateway. After a profile or point-map change, refresh BACnet point discovery.

Before applying

  1. Confirm the source address and controller profile.
  2. Use a BACnet device instance unique on your network.
  3. For a custom map, validate the CSV and review the preview.
  4. Save, wait for the gateway to reconnect, then refresh BACnet discovery.
